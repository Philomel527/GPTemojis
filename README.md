# GPTemojis

“小龙娘 GPT 娘”的聊天表情包仓库，用于 ChatGPT 项目中的公开 HTTPS 直链与 Markdown 图片嵌入。仓库保持 **Public**，默认分支为 `main`。

## 目录

- `stickers/`：正式 PNG 图片。
- [`stickers.md`](./stickers.md)：完整映射、场景、触发关键词、图片地址和可用状态，数量可持续增加。
- [`docs/GPT娘表情包目录与调用规则.md`](./docs/GPT娘表情包目录与调用规则.md)：可下载并上传到 ChatGPT 项目来源的完整自包含文档。
- [`docs/ChatGPT项目说明.md`](./docs/ChatGPT项目说明.md)：复制到 ChatGPT 项目说明中的启用指令。
- `gpt哭哭_320x320.png`：保留的原始参考图，兼容旧链接。

## 图片规范

统一角色：银白长发、淡紫色眼睛、龙角、小翅膀、鳞片尾巴、白紫色系、花饰与丝带，精致柔和可爱，带一点书卷气。参考已确认的哭哭表情，保持 Q 版比例、清晰情绪与简洁画风。

所有正式图片为 1:1 方图，推荐 320×320 PNG，优先纯白或透明背景，不增加复杂场景、文字或水印；尽量无损压缩，避免明显损失画质。现有素材保持原画。

## Raw 直链

```text
https://raw.githubusercontent.com/Philomel527/GPTemojis/main/stickers/文件名.png
```

图片上传并逐一验证 HTTP 200、PNG 有效性、方形尺寸与匿名访问后，再在索引中标记可用；预留链接不等于图片已存在。

## ChatGPT 项目使用说明

下载完整项目来源文档并加入项目来源，将启用指令放入项目说明。支持模型主动判断与用户手动指定，手动指定优先；每条回复最多一张，无匹配时正常文字回复，不伪造链接，严肃任务减少无关表情。

新聊天应读取项目说明和可访问的目录。仅有仓库无法保证模型自动记住图片映射；GitHub 更新不会保证同步到已上传的项目文件，更新后请替换来源副本。
