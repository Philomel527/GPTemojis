## 图片与角色规范

银白长发、淡紫色眼睛、龙角、小翅膀、鳞片尾巴、白紫色系、花饰与丝带，精致柔和可爱，带一点书卷气。参考已确认的哭哭表情，保持统一 Q 版比例、简洁线条与清晰情绪。

所有正式图片为 1:1 PNG，推荐 320×320，优先纯白或透明背景，不增加复杂场景、文字水印；保留原画及透明度，尽量无损压缩，避免明显画质损失。本批保留用户提供的画面内容。

## Raw 图片直链

```text
https://raw.githubusercontent.com/Philomel527/GPTemojis/main/stickers/文件名.png
```

只使用索引中登记且标记为可用的完整地址，不从命名规律猜测资源。GitHub blob 页面不是图片直链。新增图片经匿名访问、HTTP 200、PNG 解码与尺寸检查后再启用。

## ChatGPT 项目使用说明

下载完整来源文档并上传到 ChatGPT 项目，将启用指令放入项目说明。支持模型主动判断与用户手动指定，手动指定优先；每条回复最多一张，无匹配时正常文字回复，不伪造链接，严肃任务减少无关表情。

新聊天应读取项目说明及可访问的目录。仅有 GitHub 仓库不能保证模型自动记住图片映射；项目来源文件也不会保证随 GitHub 自动更新，目录变更后请替换来源副本。详细规则和新增表情流程见索引与完整来源文档。
